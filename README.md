# COS30045 Tutorial 6 – Interactive TV Energy Visualisations

## Overview

This website was developed for COS30045 Data Visualisation, Tutorial 6. It demonstrates interactive data visualisation techniques using D3.js and a dataset of televisions available in the Australian market.

## Visualisations

**1. Energy Consumption Histogram**

- Displays the distribution of labelled television energy consumption (kWh/year).
- Allows users to filter the data by screen technology and screen size.
- Uses D3 transitions to animate changes when filters are applied.

**2. Scatter Plot**

- Displays the relationship between television star ratings and screen sizes.
- Uses colour coding to distinguish screen technologies.
- Includes hover tooltips showing television brand, model and screen size.
